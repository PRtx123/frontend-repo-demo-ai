# Frontend Repo Demo AI

React приложение для управления задачами (Task Manager) - базовая версия для демонстрации ошибок разных уровней.

## Технологии

- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **React Router** - маршрутизация
- **Context API** - управление состоянием

## Структура проекта

```
src/
├── components/          # Переиспользуемые компоненты
│   ├── Layout/         # Основной layout с навигацией
│   ├── TaskCard/       # Карточка задачи
│   └── TaskForm/       # Форма создания/редактирования задачи
├── pages/              # Страницы приложения
│   ├── TaskList/       # Список задач с фильтрацией и сортировкой
│   ├── CreateTask/     # Создание новой задачи
│   └── TaskDetail/     # Детальная информация о задаче
├── context/            # React Context для state management
│   └── TaskContext.tsx # Контекст для работы с задачами
├── services/            # API сервисы
│   └── api.ts          # Моки API для работы с задачами и пользователями
├── types/              # TypeScript типы
│   └── index.ts        # Интерфейсы для Task, User и DTO
├── App.tsx             # Главный компонент приложения
└── main.tsx            # Точка входа
```

## Функциональность

- ✅ Просмотр списка задач
- ✅ Фильтрация задач по статусу
- ✅ Сортировка задач по дате и приоритету
- ✅ Создание новых задач
- ✅ Редактирование задач
- ✅ Удаление задач
- ✅ Изменение статуса задачи
- ✅ Назначение исполнителя
- ✅ Установка срока выполнения
- ✅ Приоритеты задач (низкий, средний, высокий)

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev-сервер:
```bash
npm run dev
```

3. Откройте браузер по адресу `http://localhost:5173`

## Сборка для production

```bash
npm run build
```

## Особенности реализации

- Использование Context API для глобального состояния
- Моки API с задержкой для имитации сетевых запросов
- Валидация форм на клиенте
- TypeScript для типобезопасности
- Модульные CSS стили
- Адаптивный дизайн

## Следующие шаги

Этот проект подготовлен для внесения ошибок разных уровней:
- **Junior** - базовые ошибки синтаксиса, типов, хуков
- **Middle** - проблемы с производительностью, оптимизацией, архитектурой
- **Senior** - сложные проблемы с состоянием, race conditions, memory leaks
